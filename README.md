# Restaurant Page

A simple restaurant homepage built with HTML, CSS, JavaScript modules and Webpack.

This project was created to practice generating page content with JavaScript and organizing code into separate modules. 

## Features

- Home page generated with JavaScript
- Webpack setup
- CSS imported through JavaScript
- Image assets handled with Webpack

## Built With 
- HTML
- CSS
- JavaScript
- Webpack

## What I Practiced

- JavaScript modules
- DOM manipulation
- Webpack configuration
- Importing CSS and images
- Structuring a small frontend project

## Future Improvements

- Add working Menu, About, Access and Reservation pages
- Improve mobile responsiveness
